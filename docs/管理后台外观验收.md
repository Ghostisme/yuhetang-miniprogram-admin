# 管理后台外观修复验收

本次修复保留裕和堂现有品牌配色、页面模块和 Ant Design 技术栈。普通操作按钮与可点击内容卡片分别布局，避免统计、图片、日历预约和客服会话被按钮的固定高度压缩。

## 修复范围

- 首页统计卡片恢复标题、数字、说明、图标的纵向层次及卡片间距。
- 门店选择器统一边框、浅绿选中态和悬停态；展开时保留文字对比度，移除内部输入框重复的焦点阴影。
- 图片、日历预约、客服会话、站内消息及主题选项保留各自的内容布局。
- 普通按钮、图标按钮、输入框、开关、状态标签、分页与弹窗统一品牌主题，隔离原生控件的全局样式。
- 桌面继续使用完整工作区宽度；表格、客服及长表单沿用各自的滚动区域，短屏侧边菜单可滚动。

## 2026-11-07 本地验证

`npm run build` 通过（TypeScript 检查和 Vite 生产构建）。生产构建由本地 Vite preview 提供页面后执行：

```powershell
$env:APPEARANCE_BASE='http://127.0.0.1:5183'
$env:APPEARANCE_OUTPUT='backups/admin-appearance-release'
npm run verify:appearance
$env:CHAT_VERIFY_BASE='http://127.0.0.1:5183'
npm run verify:customer-chat
```

外观检查通过 121 个页面状态，覆盖总部和门店可见模块、2560×1440、1920×1080、1366×768、390×844 四种视口，以及预约弹窗、时段卡片、品牌子页、门店子页、下拉展开、空数据首页和登录页。总部可见的 14 个模块均有覆盖；门店检查按其权限显示菜单。桌面页面无外层横向或纵向溢出，表格和客服内容在各自区域滚动。

客服回归通过 8 项检查，包含门店与状态筛选、会话读取、失败提示和不同视口。回复次数仅为浏览器模拟请求计数。

全部 API 在浏览器内使用示例数据替代，没有连接业务数据库或发送真实微信消息。上述结果验证前端构建及交互，不代表服务器已更新或真实微信投递成功。

截图和结果保存在 `backups/admin-appearance-release/`，不提交 Git。正式部署仍通过独立前端 ZIP 更新，接口采用同源 `/api/` 路径。
